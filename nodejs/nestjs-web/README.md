# NestJS Web Service

TypeScript enterprise web service with NestJS framework.

- **Stack**: Node.js / TypeScript
- **Framework**: NestJS
- **Service Type**: Web
- **Build Command**: `npm install && npm run build`
- **Start Command**: `npm start` (or `node dist/main.js`)
- **Default Port**: `3000` (respects `PORT` env var)
- **Health Check Endpoint**: `/health`
- **Root Endpoint**: `/`
