# Next.js Fullstack Web Service

Standard Next.js SSR/Static web app.

- **Stack**: Node.js
- **Framework**: Next.js
- **Service Type**: Web
- **Build Command**: `npm install && npm run build`
- **Start Command**: `npm start`
- **Default Port**: `3000` (respects `PORT` env var)
- **Health Check Endpoint**: `/api/health`
- **Index**: `/`
