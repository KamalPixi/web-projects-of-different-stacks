# Plain HTML / CSS / JS Static Site

Zero-build static site for verifying static site host hosting and CDN delivery.

- **Stack**: Static (Plain HTML / CSS / JS)
- **Build Command**: None (or leave blank)
- **Publish Directory**: `./` (current directory)
- **Key Testing Points**:
  - Serves index.html by default
  - Loads linked assets (`style.css`, `script.js`) correctly
  - Multi-page navigation works (`/about.html`)
